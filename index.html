Conventions

Harmonics. Goldberg et al., J. Math. Phys. 8, 2155 (1967), in the sign convention of LALSuite and the SXS catalog (Condon–Shortley phase included):
ₛYℓm = (−1)m √[(ℓ+m)!(ℓ−m)!(2ℓ+1) / (4π(ℓ+s)!(ℓ−s)!)] Σr C(ℓ−s, r) C(ℓ+s, r+s−m) (−1)ℓ−r−s sin2ℓ(θ/2) cot2r+s−m(θ/2) eimφ. Example: ₋₂Y22 = √(5/64π) (1+cos θ)² e2iφ. The code checks the closed forms, the identity ₛYℓ,−m = (−1)s+m conj(₋ₛYℓm) and orthonormality for all |s| ≤ 2, ℓ ≤ 5.

Axes. θ is measured from the +z axis (the grey stub at the north pole). φ is measured from +x (the short dim stub) toward +y.

Displayed field. In each cell, f = ₛYℓm · T(t), or f = ₛYℓm · T(t) + ₛYℓ,−m · T′(t) in the “m + (−m)” mode (column m ≥ 0; the m = 0 column shows ₛYℓ0 alone). T = 1 (constant) or e−iωt. The “−m term ×” buttons set the time factor of the −m term to e−iωt or e+iωt (default). The “(−1)ℓ” toggle (on by default) multiplies the −m term by (−1)ℓ. With both defaults, T′ = (−1)ℓ e+iωt. This is the mode symmetry of a nonprecessing binary, hℓ,−m = (−1)ℓ h*ℓm (reflection through the orbital plane), with hℓm = e−iωt. For s = −2 the sum is then the strain h = h+ − i h× of that (ℓ, ±m) pair. For example, ℓ = 2, m = ±2 gives circular polarization on the z axis and linear “+” polarization (h× = 0) on the equator. The code checks h× = 0 on the equator for all ℓ ≤ 5, m and t. Each sphere is normalized to its own maximum of |f| over the sphere and over one period.

s = 0. Color = Re f (blue negative, red positive). |s| = 1, 2. Color = |f|. Each glyph has length proportional to |f|. Its angle χ from eθ toward eφ is χ = sign(s) · arg(f) / |s|. Thus a vector v = vθeθ + vφeφ has spin +1 component vθ + i vφ and spin −1 component vθ − i vφ. For s = −2, f = h+ − i h×, and the segment lies along the stretch axis ψ = ½ atan2(h×, h+) of a transverse-traceless strain (h+ stretches along eθ). The |s| = 2 segments have no head, because ψ and ψ + π are the same axis.

Navigation. Drag a sphere to rotate every sphere. With “lock z vertical” on, +z points up the screen and a drag only rotates the spheres about z. The scroll wheel zooms about the cursor. Drag empty space, or shift-drag or right-drag anywhere, to pan.

Animation. ω is fixed. One period 2π/ω takes 1/speed × 4 s. For s = 0 in “m + (−m)” mode with T′ = e+iωt and (−1)ℓ off, Re f = 0 for odd m. This is correct: in that case f is purely imaginary, because Yℓ,−m = (−1)m conj(Yℓm).
